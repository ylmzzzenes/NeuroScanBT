NeuroScan / beyin BT kanama — proje düzeni
==========================================

Kök (çalıştırılabilir)
  api_server.py       FastAPI REST API
  inference.py        ResNet18 / MyCNN çıkarımı
  class_labels.py     Sınıf indeksi / checkpoint label_map yardımcıları
  arayuz.py           Tkinter masaüstü arayüzü

web/                  React (Vite) ön yüz — cd web && npm install
weights/              İsteğe bağlı ek ağırlık notları (README)
legacy/               Eski ImageFolder eğitim betikleri (train_pretrained, mycnn_pre)
training_outputs/     Eğitim sonrası üretilen PNG + metrik txt (betik çalışınca oluşur)

Ortak komutlar
  pip install -r requirements.txt
  uvicorn api_server:app --host 127.0.0.1 --port 8765
  cd web && npm run dev
