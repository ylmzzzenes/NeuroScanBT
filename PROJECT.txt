NeuroScan / beyin BT kanama — proje düzeni
==========================================

Kök (çalıştırılabilir)
  api_server.py       FastAPI REST API
  inference.py        ResNet18 / MyCNN çıkarımı
  class_labels.py     Sınıf indeksi / checkpoint label_map
  arayuz.py           Tkinter masaüstü arayüzü

training/
  train_resnet18.py   ImageFolder → best_resnet18.pth
  train_mycnn.py      ImageFolder → best_mycnn_v2.pth

web/                  React (Vite) — cd web && npm install
training_outputs/     Eğitim sonrası PNG + metrik txt (betik çalışınca güncellenir)

Ortak komutlar
  pip install -r requirements.txt
  uvicorn api_server:app --host 127.0.0.1 --port 8765
  cd web && npm run dev
